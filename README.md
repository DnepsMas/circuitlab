# CircuitLab 芯片实验室（网页版）

74LS 芯片级数字电路实验平台：按真实 DIP 引脚接线，实时仿真组合与时序电路，三个课程实验自动判定；内置 AI 工作台，用中文对话让助手搭电路并用仿真自检。

**在线使用：<https://dnepsmas.github.io/circuitlab/>**

- 本仓库只包含构建好的静态网页（版本 1.5.4），由 GitHub Pages 托管。
- 电路、实验进度与设置保存在浏览器本地，刷新后自动恢复。
- AI 工作台需要自备 DeepSeek API Key；网页版由浏览器直连 DeepSeek，可能受网络或跨域限制，推荐使用 Windows 桌面版（安装版 / 便携版 exe）。
